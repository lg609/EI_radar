# 具身智能情报前沿｜家庭机器人进入人机共处数据阶段

**作者：具身视界** · 2026.07.06

> 今天最值得关注的变化，是家庭机器人赛道正在从“机器人能不能完成家务动作”，转向“机器人能不能在人类在场、空间杂乱、物品易损的真实家庭里安全协作”。1X、Figure、Matic 等公司都把家庭作为产品叙事核心，HABIT、OopsieVerse、RoboCasa 等研究则在补齐人机共处、安全损伤和日常任务数据底座。

## 💥 今日重磅

### [HABIT：10K+ episode、160+ 小时数据，把机器人训练放进“有人在场”的家庭式环境](https://arxiv.org/abs/2606.31682v1)

**摘要：** 6 月 30 日发布的 HABIT 直接击中家庭机器人落地的核心短板：大量机器人示范数据是在“没有人”的环境中采集的，策略在孤立任务里可能完成得不错，但一旦进入真实家庭，就必须理解人正在旁边做什么、什么时候让行、什么时候协作、什么时候接受监督。HABIT 将任务组织为 Collaborator、Coworker、Supervisor 三类人机互动角色，覆盖协作完成任务、共享空间各做各事、人类指挥机器人三种家庭/办公高频关系。数据集包含 60 个任务、10K+ episodes、160+ 小时数据。实验显示，用 HABIT 训练能诱发 robot-only 数据无法带来的行为：协作任务中的时空同步、共处任务中的让行、监督任务中的手势 grounding，并能快速适配新的人机交互任务。对 1X、Figure、Unitree、Agibot 等瞄准家庭和通用场景的公司来说，HABIT 传递的信号很明确：家庭机器人不是把仓库机器人搬进客厅，而是要把“有人在场”作为训练数据的一等变量。

- **来源：** arXiv
- **核心价值：** 家庭机器人竞争正在从单体动作能力转向人机共处数据，谁先把人类在场、让行、协作和监督纳入训练闭环，谁更接近真实家庭部署。

## 📑 前沿论文

### 1. [OopsieVerse：家庭机器人必须区分“任务完成”和“不造成损伤”](https://arxiv.org/abs/2606.31993v1)

**摘要：** OopsieVerse 面向家庭操作安全，指出任务成功并不等于可部署：机器人如果压坏物品、烫坏表面、打翻液体，即使完成目标也不可接受。它提出 DamageSim，将接触力、温度变化、液体交互转化为机械、热和流体损伤信号，并在 OmniGibson 和 RoboCasa 后端中实例化。框架可用于安全示范采集、损伤条件模仿学习和强化学习、VLA 安全评测及 sim-to-real 安全改进。

- **作者团队：** Arnav Balaji、Arpit Bahety、Sriniket Ambatipudi、Daniel Lam、Junhong Xu、Roberto Martin-Martin
- **来源：** arXiv / 项目页
- **核心价值：** 家庭机器人评测必须把“成功率”拆成任务完成、损伤风险和安全副作用三套指标。

### 2. [Freeform Preference Learning：让用户用自然语言定义“更小心、更快、更稳”](https://arxiv.org/abs/2606.32027v1)

**摘要：** Freeform Preference Learning 关注长时序操作中的人类偏好学习。它不要求标注者只在两条轨迹里选“整体更好”，而是允许人用自然语言定义偏好轴，例如速度、安全、放置质量、谨慎程度，再沿每个轴提供偏好。方法学习语言条件奖励模型，并训练 reward-conditioned policy。4 个真实世界和 2 个仿真长时序操作任务中，FPL 比稀疏奖励和二元偏好方法高 38 个百分点。

- **作者团队：** Marcel Torne、Anubha Mahajan、Abhijnya Bhat、Chelsea Finn
- **来源：** arXiv
- **核心价值：** 家庭机器人必须服务不同用户偏好，策略需要能按“更快”或“更小心”等自然语言目标切换行为。

### 3. [WorldSample：真实机器人 RL 用世界模型降低家庭式操作试错成本](https://arxiv.org/abs/2607.02431v1)

**摘要：** WorldSample 通过 real-synthetic loop 将真实 rollout、世界模型生成和策略改进连起来。基于真实轨迹生成高保真合成 transition，再用 Policy-Paced Learning 调度样本，避免幻觉导致价值高估。在接触丰富和精密操作任务中，WorldSample 将策略成功率提升 28%，训练步数减少 59%，世界模型视觉保真度提升 19.4dB PSNR 和 0.47 SSIM。

- **作者团队：** Yuquan Xue、Le Xu、Zeyi Liu、Zhenyu Wu、Zhengyi Gu、Xinyang Song、Bofang Jia、Ziwei Wang
- **来源：** arXiv
- **核心价值：** 数据相关报道：家庭机器人很难靠真实试错堆数据，世界模型增强会成为降低物理交互成本的重要路线。

### 4. [Agentic RAG-VLM：杂乱家庭场景抓取需要理解材料、易碎性和可抓区域](https://arxiv.org/abs/2606.31200v1)

**摘要：** Agentic RAG-VLM 面向杂乱环境中的泛化抓取。它不再只用视觉相似度匹配物体，而是编码类型、材料、易碎性和可抓区域四维 affordance 描述，并结合场景图约束推理与 14 类失败分类的自反思重试机制。12 个任务、每配置 360 次试验中，整体成功率达到 78.3%，比 VLM-only 基线高 53.3 个百分点。

- **作者团队：** Tao Chen、Lizheng Liu、Jiaxu Wang、Ziyue Jiang、Ruiqi Tian、JiGuang Huo、Zhongxue Gan
- **来源：** arXiv
- **核心价值：** 家庭抓取不是“看见杯子就抓”，而是要知道杯柄、材质、易碎性、遮挡关系和失败后如何重试。

### 5. [用户感知研究：抓取成功率从 75% 到 90%，70.83% 参与者能感知差异](https://arxiv.org/abs/2607.00530v1)

**摘要：** 这项 HRI 用户研究比较了同一桌面抓取任务中的两个多模态系统：基线端到端成功率 75%，改进系统 90%。24 名参与者体验后，17 人更偏好改进系统，占 70.83%；速度、可靠性、整体能力和流畅性评分均显著提升。对家庭机器人来说，这说明离线技术指标只有在用户能明显感知时，才会转化为产品体验优势。

- **作者团队：** Jian Song、Tian Zi、Shen Guanting
- **来源：** arXiv
- **核心价值：** 家庭机器人产品评估不能只看 benchmark，还要看用户是否真的感到更可靠、更流畅。

## 💻 开源生态

### 1. [RoboCasa：日常家庭任务仿真仓库星标超过 1500](https://robocasa.ai/)

**摘要：** GitHub API 显示，robocasa/robocasa 星标约 1518，7 月 4 日仍有更新记录，仓库描述为“Large-Scale Simulation of Everyday Tasks for Generalist Robots”。RoboCasa 的价值在于提供日常任务仿真环境，让家庭机器人策略能在厨房、物品摆放、清理整理等场景中进行可复现实验。

- **来源：** GitHub
- **核心价值：** 家庭机器人需要大规模日常任务仿真，否则真实家庭数据采集成本和安全风险都过高。

### 2. [OopsieVerse 开源：家庭损伤评测开始工具化](https://robin-lab.cs.utexas.edu/oopsieverse/)

**摘要：** OopsieVerse 项目页可访问，GitHub API 显示其仓库 7 月 1 日仍有推送。它把损伤评测从“人工看视频判断是否危险”推进到机械、热、流体损伤信号的可计算框架。对家庭机器人开发者来说，这类工具能在策略训练阶段提前暴露安全副作用。

- **来源：** 项目页 / GitHub
- **核心价值：** 家庭赛道的开源基础设施会从任务成功率扩展到损伤、风险和安全偏好。

### 3. [NVIDIA Isaac GR00T 星标约 7500：平台层需要承接家庭机器人长尾任务](https://developer.nvidia.com/isaac/gr00t)

**摘要：** GitHub API 显示，NVIDIA/Isaac-GR00T 星标约 7500，6 月 30 日仍有推送。家庭机器人和工业机器人最大的不同在于任务长尾、环境动态、人类在场和安全偏好复杂。GR00T 这类基础模型平台如果要服务家庭赛道，需要将任务数据、仿真、安全评测和人类偏好训练纳入统一工具链。

- **来源：** GitHub
- **核心价值：** 家庭机器人不会只拼本体，平台能否支撑长尾任务和安全数据闭环同样关键。

## 结尾总结

7 月 6 日这条主线很明确：家庭机器人赛道正在从产品想象进入数据和评测补课阶段。1X、Figure 把家庭帮助放进官方叙事，Matic 代表窄任务家用机器人仍有现实商业路径，Unitree 和 NVIDIA 则提供本体与平台生态。但真正决定家庭机器人能否进入普通家庭的，是 HABIT 这类人机共处数据、OopsieVerse 这类损伤安全评测、RoboCasa 这类日常任务仿真，以及 Freeform Preference Learning 这类用户偏好学习。
