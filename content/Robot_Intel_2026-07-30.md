## 📚 前沿论文

### 1. [Data Pyramid：把具身数据生态拆成五层金字塔](https://arxiv.org/abs/2607.24744)

**摘要：** 7 月 27 日提交的 Data Pyramid for Embodied Manipulation 指出，具身智能没有互联网文本那样的捷径，因为机器人需要同时包含观测、物理状态和动作的数据。论文把具身数据生态组织为五类来源：真实机器人数据、UMI 风格数据、第一视角与第三视角数据、仿真数据、通用视觉语言数据，并围绕可扩展性和机器人对齐度分析各类数据的质量、多样性、可复用性和物理保真度。

- **作者团队：** Yifan Ye / Yao Mu / Ziwei Liu / Jianfei Yang / Ping Luo / Shanghang Zhang 等
- **来源：** arXiv
- **核心价值：** 数据相关报道：未来大会和评测讨论的核心会越来越像“数据配方”问题，而不是单纯比较模型名称。

### 2. [ArmnetBench v0.1：低成本机械臂农场并行评测 7 个策略、12 个任务](https://arxiv.org/abs/2607.24481)

**摘要：** 7 月 27 日提交的 ArmnetBench v0.1 面向真实世界策略评测瓶颈。该基准运行在低成本 SO-101 单元组成的机械臂农场上，在轻量现场监督下比较 7 个策略、12 个任务，覆盖单臂和双臂配置。论文包含 2,518 次策略 rollout 和 600 条参考示范，共 3,118 个 episode，并标注成功、次优、失败三类标签。

- **作者团队：** Praveen Selvaraj / Lorenzo Uttini / Ville Kuosmanen
- **来源：** arXiv
- **核心价值：** 当机器人大会进入密集展示季，行业更需要低成本、可复现、可横向比较的真实评测，而不是只看单机演示视频。

### 3. [LabRobFail：化学自驱实验室的机器人失败分析基准](https://arxiv.org/abs/2607.23704)

**摘要：** 7 月 26 日提交的 LabRobFail 面向化学自驱实验室中不可逆、强安全约束的机器人执行问题。论文提出失败中心化框架，LabRobFail-Sim 可在控制、物理、语义层注入可控失败，构建超过 20,000 条轨迹、70 多个任务场景、5 类失败和 11 个细粒度失败类型的数据，并评估任务理解、失败检测、时间定位、严重度评估、失败分类和可执行纠正能力。

- **作者团队：** Haobo Wang / Baoli Sun / Anqi Zou / Wanli Ouyang 等
- **来源：** arXiv
- **核心价值：** 真实落地不是只比成功率，失败识别与纠正会成为科研机器人、工业机器人和具身智能系统共同需要的评测项。

### 4. [ViTacWorld：接触丰富操作走向视觉-触觉世界模型](https://arxiv.org/abs/2607.22530)

**摘要：** 7 月 24 日提交的 ViTacWorld 针对接触丰富操作中“摄像头看不见的物理交互”。论文提出 action-conditioned 视觉-触觉世界模型，利用公开真实触觉数据和仿真环境扩展视觉-触觉-动作数据，并通过真实策略 rollout 微调，使模型更贴近下游操作行为。它强调触觉信号直接来自物理接触，可能比纯视觉观测具有更小的 sim-to-real 差距。

- **作者团队：** Yunao Huang / Shiyu Sang / Haotao Lu / Jingya Wang 等
- **来源：** arXiv
- **核心价值：** 未来展会上，灵巧操作和工业装配不只需要“看得见”，更需要机器人能感知接触、压力和滑移。

## 🧩 开源生态

### 1. [Embodied Data Pyramid：具身数据路线图已开放项目页与资料库](https://jasper-aaa.github.io/embodied-data-pyramid/)

**摘要：** Data Pyramid 项目页和 GitHub 资料库已开放，围绕真实机器人、UMI、第一/第三视角、仿真、通用视觉语言数据构建具身数据路线图。它适合作为活动季前的资料底图：看一家公司发布数据集或训练系统时，可以反问它的数据处在金字塔哪一层、可扩展性和机器人对齐度如何。

- **来源：** 项目主页 / GitHub
- **核心价值：** 数据路线图会帮助行业从“谁的数据更多”转向“谁的数据更适合训练可部署机器人”。

### 2. [ArmnetBench v0.1：Hugging Face 集合开放低成本真机评测数据](https://huggingface.co/collections/armnet/armnetbench-v01)

**摘要：** ArmnetBench v0.1 的 Hugging Face 集合可访问，围绕低成本机械臂农场提供真实评测数据。对开源社区而言，这类资源的价值在于降低复现实验门槛：团队可以在共同任务、共同预算和共同标签体系下比较策略，而不是各自发布不可横向比较的成功率。

- **来源：** Hugging Face
- **核心价值：** 评测基础设施会成为具身智能开源生态的重要层级，尤其适合承接大会后的模型复现和排行榜建设。

### 3. [LabRobFail / SciRobo：失败数据与实验室机器人评测代码开放](https://github.com/Su-ISE-2001/SciRobo)

**摘要：** LabRobFail 论文关联的 SciRobo GitHub 仓库可访问，服务于化学自驱实验室的机器人失败分析与评测。它把“失败”从事故记录变成可生成、可标注、可训练、可评测的数据对象，对高风险场景尤其关键。

- **来源：** GitHub
- **核心价值：** 未来机器人活动中的技术展示如果只展示成功样例，信息量会不够；能公开失败分析能力，才更接近真实部署。

### 4. [S2A2：音频-视觉模仿学习把声源定位引入操作任务](https://azuma413.github.io/projects/s2a2)

**摘要：** 7 月 28 日提交的 S2A2 项目页可访问。该工作提出 acoustic-aware manipulation tasks，要求机器人利用声音判断操作目标，并将视觉特征、声学空间信息和声学信号整合进 ACT、Diffusion Policy、VQ-BeT、π0 等策略框架。仿真结果显示，该方法在需要位置和音色共同判断的任务中更有效，真实机器人实验也验证了可行性。

- **来源：** 项目主页 / arXiv
- **核心价值：** 展会现场常见的是视觉 demo，但真实家庭、门店和工厂里，声音也是定位、材质和接触状态的重要线索。

- **核心价值：** 赛题会倒逼技术路线从“单点动作能力”转向“复杂环境中的协同能力”。

### 2. [BCI 脑控机器人大赛：脑机接口与具身智能同场出现](https://www.worldrobotconference.com/contest/BCIBrainControlRobotCompetition/2026.html)

**摘要：** 世界机器人大会官网的 BCI 脑控机器人大赛页面提到，具身智能、第六代移动通信等成为新的经济增长点。脑控机器人虽然距离大规模商业化仍远，但它代表了人机交互的另一个方向：当机器人进入康复、助残、医疗和增强场景，意图识别不一定只来自语音和视觉，也可能来自生理信号。

- **来源：** 世界机器人大会官网
- **核心价值：** 活动预告中的 BCI 赛项说明，具身智能未来不只是机器人本体竞争，也会与脑机接口、康复工程和多模态交互深度耦合。

### 3. [NeoteAI 与复旦团队：触觉大模型路线继续升温](https://arxiv.org/abs/2607.23782)

**摘要：** 7 月 26 日，NeoteAI Team 与 Fudan TEAI Team 提交 N0-VTLA 与 N0-TWAM 两篇触觉相关工作。其中 N0-VTLA 面向视觉-触觉-语言-动作模型，强调基于大规模触觉数据的预训练和离线策略改进；N0-TWAM 则面向触觉原生 world-action model，预测未来视觉与未来接触，并覆盖六种本体、450 个任务的触觉丰富示范。

- **来源：** arXiv
- **核心价值：** 如果 8 月大会集中展示灵巧操作，触觉数据、触觉模型和接触事件分段会成为判断技术深度的重要指标。
