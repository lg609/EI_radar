# 具身智能情报前沿｜政策开始定义身体边界

**作者：具身视界** · 2026.07.23

---

> 今天最值得关注的变化，是具身智能正在从“技术展示”进入“政策、标准和治理边界”阶段。WAIC 官方 7 月 17 日发布《2026世界人工智能大会暨人工智能全球治理高级别会议主席声明（全文）》，其中明确提到数据制度、智能体决策权限、行为边界、风险提示、安全护栏和标准制修订。对机器人行业来说，这些词会直接影响未来本体、模型、数据和场景落地。

## 💥 今日重磅

### 1. [WAIC 主席声明发布：智能体边界、数据安全和标准制修订进入全球治理议程](https://www.worldaic.com.cn/news/a7a32ea4f41f4e86937f51ec201e84b4)

**摘要：** WAIC 官方新闻显示，《2026世界人工智能大会暨人工智能全球治理高级别会议主席声明（全文）》于 2026 年 7 月 17 日 14:00 发布。声明指出，2026 世界人工智能大会暨人工智能全球治理高级别会议于 7 月 17-20 日在中国上海举行，主题为“智能伙伴 共创未来”，并提出一系列治理主张：统筹发展和安全，平衡创新和治理；深化数据资源开发利用，保障数据安全，构建数据产权等基础制度，确保数据可管、可控、可追溯；重视 AI 安全风险，推动法律法规、技术监测、风险预警和应急响应体系；智能体作为 AI 产品和服务新形态，应明确决策权限和行为边界，建立行为追溯和风险提示机制；加快安全、产业、伦理标准制修订。声明还提到《关于成立世界人工智能合作组织的协定》签署仪式在上海举行，世界人工智能合作组织总部将设在上海。对具身智能而言，这意味着机器人不再只受技术路线驱动，还会被数据合规、智能体权限、现场安全和标准互认共同塑形。

- **来源：** 世界人工智能大会官网
- **核心价值：** 政策已经开始定义具身智能的“身体边界”：机器人能看什么数据、能做什么动作、谁能追溯责任、哪些安全护栏必须前置，都会变成产业化条件。
- **行业判断：** 具身智能下一阶段不是只比谁的模型更强，而是比谁能在政策、标准和客户安全要求下稳定部署。

### 3. [主席声明提出加快安全、产业、伦理标准制修订：机器人标准化窗口打开](https://www.worldaic.com.cn/news/a7a32ea4f41f4e86937f51ec201e84b4)

**摘要：** 声明第十四项提出，应加快安全、产业、伦理标准制修订，兼顾技术进步、风险防范、社会伦理，建立科学、透明、包容的标准规范框架，并促进各国间标准互认。对具身智能产业链而言，这会影响本体接口、数据采集、遥操作、模型部署、故障记录、安全停机和人机交互评测等环节。

- **来源：** 世界人工智能大会官网
- **核心价值：** 标准不是行政附属品，而是规模化部署的前置条件；没有通用接口和安全评测，机器人很难跨客户、跨场景复制。

## 📚 前沿论文

### 1. [Risk-Aware Belief Control Barrier Functions：未知动态环境中的风险感知安全控制](https://arxiv.org/abs/2607.15016)

**摘要：** 7 月 16 日提交的论文研究未知动态环境中的机器人安全控制。论文指出，机器人需要从噪声和不完整观测中推断未知且数量变化的移动物体状态，并在多目标不确定性下保持安全。作者提出 risk-aware belief control barrier function，将不确定性表示为 random finite set belief，并用 SMC-PHD filter 的粒子构建非光滑 BCBF，给出安全集前向不变性与离散更新保持安全的条件，并在仿真和真实水下实验中验证。

- **来源：** arXiv
- **核心价值：** 政策要求“风险预警、技术监测、应急响应”最终要落到控制算法；安全控制函数是把治理要求翻译成机器人动作约束的一类工程工具。

## 🧩 开源生态

### 1. [rosclaw 7 月 22 日推送：Physical AI 运行时把沙箱安全和能力路由写进基础设施](https://github.com/ros-claw/rosclaw)

**摘要：** GitHub API 显示，ros-claw/rosclaw 7 月 22 日有推送，星标约 170。项目描述为面向 Physical AI 和 embodied agents 的自演化运行时基础设施，包含 e-URDF、sandbox safety、capability routing、praxis capture、physical memory、runtime intervention 和 skill evolution 等模块。

- **来源：** GitHub
- **核心价值：** 当政策要求智能体明确行为边界，机器人运行时就不能只是调度任务，还要内置能力声明、安全沙箱、运行干预和行为记忆。

### 2. [NVIDIA Halos Outside-In Safety 7 月 22 日推送：外部基础设施摄像头参与机器人安全控制](https://github.com/NVIDIA/halos-outside-in-safety)

**摘要：** GitHub API 显示，NVIDIA/halos-outside-in-safety 7 月 22 日有推送，星标约 57。项目描述称，Halos Outside-In Safety Blueprint 通过外部基础设施摄像头和 AI agents 扩展机器人感知，用于动态控制机器人行为并提升效率。它代表了一种治理侧思路：安全不只依赖机器人本体传感器，也可以由场地基础设施参与。

- **来源：** GitHub
- **核心价值：** 具身机器人进入工厂、仓储、展馆和公共空间后，安全边界会从单机扩展到场地级感知和调度系统。

### 3. [Robot Safety Sandbox 7 月 20 日推送：安全策略训练和安全过滤评测需要并行环境](https://github.com/SafeRoboticsLab/robot-safety-sandbox)

**摘要：** GitHub API 显示，SafeRoboticsLab/robot-safety-sandbox 7 月 20 日有推送。项目描述为 Robot Safety Sandbox，提供并行 mjlab 环境，用于 nominal-policy training、safety-policy synthesis 和 safety-filter evaluation。它把机器人安全从口号变成可训练、可合成、可评测的实验环境。

- **来源：** GitHub
- **核心价值：** 数据相关报道：安全策略需要可重复评测数据和环境；没有 sandbox，政策中的安全要求很难转化为可验证指标。

## 结尾总结

7 月 23 日的主线可以概括为：具身智能正在被政策和治理框架重新定义。WAIC 主席声明把数据、智能体边界、安全护栏、标准制修订和国际合作组织放到同一张桌面上；开源运行时和安全论文则说明，政策要求正在向工程层下沉。未来机器人公司不仅要证明“能做任务”，还要证明“在授权边界内、安全、可追溯、可评测地做任务”。
