# 具身智能情报前沿｜零部件进入力控校准

**作者：具身视界** · 2026.07.26

---

> 今天最值得关注的变化，是具身智能核心零部件正在从“参数表竞争”进入“力、触觉、惯性、执行器模型可被训练和校准”的阶段。过去 7 天，力控装配、合成触觉、低层控制器、IMU 自监督、执行器摩擦建模等论文和开源项目集中活跃，说明机器人真正落地的瓶颈正在下沉到关节、夹爪、传感器和控制接口。

## 💥 今日重磅

### [FORGE-plus：把易碎物体装配写成力预算问题，256/256 次评测无破损](https://arxiv.org/abs/2607.21227)

**摘要：** 7 月 23 日提交的 FORGE-plus 聚焦接触丰富装配中的核心零部件问题：夹爪、低层控制器和力传感信号如何共同保证“不压坏”。论文提出两层框架，由冻结的文本 LLM 在执行前为不同物体分配 force ceiling，并根据紧凑的 force signature 选择恢复动作；真正的力执行仍由低层控制器约束，恢复策略不能自行提高力上限。作者在易碎瓶体放置和 0.4 mm 间隙齿轮插入中评测 Robotiq 2F-140 与 Franka Panda hand，单一策略在易碎和坚固物体上通过 256/256 次评测且无破损，完整 pick-and-insert 管线平均峰值力为 5.4 N。它的重要性在于，具身智能不只需要“会抓”，还要知道每个末端执行器、物体和接触状态下能用多大力。对夹爪厂商、力传感器、控制器和整机公司来说，未来可交付能力会越来越依赖可验证的力预算、故障恢复和接触安全边界。

- **来源：** arXiv
- **核心价值：** 核心零部件竞争正在从“最大负载、自由度、响应速度”转向“力能否被预算、执行、记录和恢复”；这是机器人从演示走向真实装配的关键门槛。
- **行业判断：** 具身机器人要进入工厂、家庭和服务场景，夹爪和控制器必须先从“动作执行件”升级为“力安全基础设施”。

### 3. [DINS-IO：IMU 原始流可自监督学习，惯性传感器数据不再完全依赖高精定位标签](https://arxiv.org/abs/2607.20232)

**摘要：** 7 月 22 日提交的 DINS-IO 提出直接从原始 IMU 流学习惯性里程计，利用可微 strapdown INS 一致性作为自监督约束，并通过少量标注轨迹做度量校准。对机器人零部件来说，IMU、编码器、力传感器这类“小传感器”常被低估，但它们决定了机器人在视觉遮挡、快速运动和低成本场景中的状态估计下限。

- **来源：** arXiv
- **核心价值：** 数据相关报道：传感器价值不只在硬件精度，还在数据能否低成本校准；自监督 IMU 学习会降低高精真值采集依赖。

## 📚 前沿论文

### 1. [FELT：从 RGB 合成每指压力触觉，缓解触觉传感器数据稀缺](https://arxiv.org/abs/2607.20683)

**摘要：** 7 月 22 日提交的 FELT 指出，触觉对遮挡和接触不确定场景很关键，但触觉传感器脆弱、专用且难标准化，导致数据远少于视觉。论文用冻结视觉编码器和轻量 query decoder，从 RGB 预测每指压力 tactile images，并尊重双指触觉面板的物理拓扑。四个接触丰富任务显示，生成触觉图像和潜在触觉特征都能提升策略成功率。

- **作者团队：** Zinan Li / Yiyang Ling / Yuming Gu / Yunzhu Li / Stefanos Nikolaidis / Daniel Seita 等
- **来源：** arXiv
- **核心价值：** 触觉硬件短期难以大规模普及，先用视觉补出触觉特征，可能成为低成本灵巧操作数据路线。

### 2. [URF：让策略同时预测动作与控制器行为，减少刚性接触中的力振荡和工具损坏](https://arxiv.org/abs/2607.20912)

**摘要：** 7 月 23 日提交的 URF 关注学习策略与低层控制器割裂的问题。论文让策略根据多模态观测预测虚拟目标、刚度矩阵和 impedance-admittance switch ratio，决定控制器何时偏向 admittance 以追踪运动，何时偏向 impedance 以保证刚性接触安全。作者用实测接触力构造 switch-ratio 标签，在翻箱和压线任务中减少快速力堆积、力振荡、工具破损和安全停机。

- **作者团队：** Jiyou Shin / Youngjin Seo / Jaeseog Won / Hyungpil Moon 等
- **来源：** arXiv
- **核心价值：** 控制器不是策略之后的附属执行层；接触任务里，控制器模式本身应该成为策略预测对象。

### 3. [V2F：视觉预测安全抓取力，易损水果残余形变低于 1 mm](https://arxiv.org/abs/2607.19804)

**摘要：** 7 月 22 日提交的 V2F 面向椰枣等易损水果处理，先做机械表征定义安全抓取包络，再用视觉分割、几何特征和物理残差网络预测安全抓取力。实验中，模型对未见品种组的平均验证表现约 `R^2≈0.7`，并在夹爪与 load cell 验证中实现稳定操作，残余形变低于 1 mm 且无可见损伤。

- **作者团队：** Shahd Shami / Obadah Wali / Eric Feron / Shinkyu Park
- **来源：** arXiv
- **核心价值：** 末端执行器的真实能力不只看夹持力上限，而是能否根据物体材料和几何提前选择安全力。

## 🧩 开源生态

### 1. [PACE 7 月 20 日推送：执行器与关节动力学识别继续成为 sim-to-real 关键入口](https://github.com/leggedrobotics/pace-sim2real)

**摘要：** GitHub API 显示，leggedrobotics/pace-sim2real 7 月 20 日有推送，星标约 614。项目描述为用标准关节编码器识别 legged robots 的 actuator and joint dynamics，服务 sim-to-real transfer。它直接击中核心零部件问题：如果执行器真实摩擦、延迟、饱和和关节动态没有被建模，仿真训练出的策略很难稳定迁移到真机。

- **来源：** GitHub
- **核心价值：** 数据相关报道：执行器不是黑盒采购件，而是需要被识别、建模和持续校准的数据对象。

### 2. [Rhoban/bam 7 月 24 日活跃：舵机执行器摩擦模型走向开源仿真](https://github.com/Rhoban/bam)

**摘要：** GitHub API 显示，Rhoban/bam 7 月 24 日有推送，星标约 218。项目描述为 identify and simulate extended friction models for servo-actuators，并带有 actuator、friction、MuJoCo、robotics-simulation 等标签。对低成本机器人和小型关节来说，舵机摩擦、死区、回差和热漂移会直接影响动作稳定性，开源摩擦模型有助于把这些问题前置到仿真阶段。

- **来源：** GitHub
- **核心价值：** 零部件建模越早进入开源生态，整机团队越容易在设计阶段发现关节和执行器的真实边界。

### 3. [HandUMI 硬件与软件 7 月 22-23 日更新：穿戴式采数把夹爪接口、校准和质检连起来](https://github.com/robonet-ai/handumi-sw)

**摘要：** GitHub API 显示，robonet-ai/handumi-sw 7 月 23 日推送，handumi-hw 7 月 22 日推送。HandUMI 软件用于同步双臂数据采集、重定向、校准、QA、回放和遥操作；硬件是手戴式 UMI 变体，用于不依赖机器人本体采集双臂操作数据，并可模块化适配 parallel-jaw gripper。它把夹爪、遥操作、校准和数据质检组织成完整零部件数据链。

- **来源：** GitHub
- **核心价值：** 夹爪和末端执行器要进入模型训练，必须先有稳定的采集、校准、重定向和质检工具链。

## 🏢 机器人公司情报

### 1. [Robotiq 与 Franka 作为 FORGE-plus 评测夹爪：成熟末端执行器正在成为力控算法基准载体](https://arxiv.org/abs/2607.21227)

**摘要：** FORGE-plus 在评测中使用 Robotiq 2F-140 与 Franka Panda hand，任务包括易碎瓶体放置和 0.4 mm 间隙齿轮插入。虽然论文不是公司新闻，但这类成熟夹爪和机械手频繁出现在研究评测中，说明它们已成为力控、安全恢复和接触策略比较的事实载体。未来客户采购末端执行器，也会越来越看其是否被主流算法、数据集和评测流程支持。

- **来源：** arXiv
- **核心价值：** 核心零部件的生态位来自“可被集成和可被评测”；出现在高质量研究基准中，本身就是产业信号。

### 2. [Unitree G1 出现在 YAHMP 实证研究：人形本体倒逼执行器配置、动作表示和接触力训练可量化](https://arxiv.org/abs/2607.19903)

**摘要：** 7 月 22 日提交的 What Matters in Humanoid General Motion Tracking? 使用开源模块化框架 YAHMP，在 Unitree G1 上训练、评估和部署全身运动跟踪策略。论文比较 motion-command representation、observation history、action representation、actuation profile、hand-force randomization 等因素，并在真机上展示零样本部署、扰动平衡和 forceful interaction。

- **来源：** arXiv
- **核心价值：** 人形机器人竞争会继续下沉到执行器配置、动作接口和接触力训练；本体参数必须和策略训练指标绑定，才有工程意义。

### 3. [ModPack：可穿戴“背包”把算力、电源、通信和数据存储做成遥操作接口模块](https://arxiv.org/abs/2607.19479)

**摘要：** 7 月 21 日提交的 ModPack 提出面向双臂移动操作的模块化遥操作系统，核心是自包含可穿戴 “backpack”，集成 onboard computation、power、communication 和 data storage，并支持带触觉反馈的关节级遥操作、移动操作和主动感知模块。对机器人公司来说，这类接口设备会影响数据采集成本，也会决定不同本体和末端执行器能否共享同一套遥操作流程。

- **来源：** arXiv
- **核心价值：** 具身数据采集不只是软件问题，背后的电源、通信、存储、触觉反馈和关节级接口都是核心零部件生态的一部分。

## 结尾总结

7 月 26 日的主线可以概括为：具身智能核心零部件正在数据化和控制化。力控装配、合成触觉、IMU 自监督、执行器动力学识别和舵机摩擦建模共同说明，机器人性能不再只由整机外观决定，而是由夹爪、关节、传感器、控制器和采数接口能否被建模、校准和验证决定。
