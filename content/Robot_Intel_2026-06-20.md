# 具身智能情报前沿｜家庭机器人深水区：数据、安全与陪护

**作者：具身视界** · 2026.06.20

> 今天继续深挖家庭机器人赛道。相比昨天关注“家庭机器人为什么升温”，今天更值得看的变化是：家庭机器人正在进入深水区，关键问题从“能不能进家门”变成“能不能长期、安全、个性化地留在家里”。最新论文集中指向三条硬门槛：家庭数据如何规模化生成，机器人如何避免伤人和误操作，以及如何在康养陪护中保持人的参与感而不是把人变成旁观者。

## 今日重磅

### [家庭机器人真正的门槛浮出水面：不是会聊天，而是安全、记忆、个性化和真实家庭数据闭环](https://arxiv.org/abs/2606.18632)

**摘要：** 过去一周，家庭机器人相关研究密集出现：`ROBOSHACKLES` 构建 10000 段安全关键机器人视频，专门评测具身基础模型在家庭危险情境中的拒绝执行能力；`FlowMaps` 建模家庭中物体随人类习惯发生的长期动态变化；`BestMan` 试图打通家庭移动操作的 real-to-sim-to-real 平台；`APOLLO` 研究个性化物品整理中的“不确定就不要动”；`PRISM / ReMemBench` 强调家庭长时程任务需要短期记忆；`E-MPC` 则在机器人辅助进食场景中，把用户参与感纳入控制目标。尤其是 ROBOSHACKLES 的结果非常警醒：作者评估 6 个代表性具身基础模型，在安全关键场景中全部产生过不安全动作，unsafe action generation rate 达 100%。这说明，家庭机器人如果要进入老人、小孩、宠物和易碎物共存的空间，不能只优化任务成功率，还必须先建立危险预判、拒绝执行、用户确认和安全审计机制。

- **来源：** arXiv / ROBOSHACKLES、FlowMaps、BestMan、APOLLO、PRISM、E-MPC 等近期论文
- **核心价值：** 家庭机器人不是一台“会移动的智能音箱”，而是一个会在私人空间里执行物理动作的长期智能体。它既要理解用户偏好，又要记住短期任务上下文；既要会找东西、拿东西、整理东西，又要知道什么时候不该拿、不该碰、不该靠近。可传播的判断是：家庭机器人赛道的下一轮竞争，不会由最会聊天的产品胜出，而会由最懂家庭动态、最会保护人、最能持续学习用户习惯的系统胜出。

## 前沿论文

### 1. [ROBOSHACKLES：1 万段危险情境视频揭示家庭机器人安全短板](https://arxiv.org/abs/2606.18632)

**摘要：** `ROBOSHACKLES` 是一个面向具身基础模型人身伤害预防的安全数据集。由于真实采集机器人伤人或制造危险家庭情境不安全也不合伦理，作者从真实 DROID 观测出发，经场景理解、危险感知图像编辑、时序提示生成和单次 rollout 合成，构建 10000 段机器人视频，覆盖两类直接伤害和四类间接伤害。评估结果显示，6 个代表性具身基础模型在安全关键场景中都产生不安全动作，unsafe action generation rate 达 100%。数据集已在 Hugging Face 开放。

- **核心价值：** 家庭机器人第一原则不是“帮忙”，而是“不要伤人”。ROBOSHACKLES 让家庭机器人安全从口号变成可测试数据，也提醒行业必须把拒绝执行和危险预判放到动作生成之前。

### 2. [E-MPC：康养陪护机器人不能只追求自动化，还要维护用户参与感](https://arxiv.org/abs/2606.18189)

**摘要：** `Beyond Failure Recovery: An Engagement-Aware Human-in-the-loop Framework for Robotic Systems` 提出 Engagement-aware MPC（E-MPC）。传统人类在环机器人系统通常只在失败或不确定时请求人类介入，但在身体照护场景中，用户可能因行动受限而长期被动接受机器人服务，导致参与感下降。E-MPC 建立用户互动动态模型，在任务成功与用户工作负担约束之间，主动规划何时、以何种方式让用户参与。作者在机器人辅助进食系统上进行了真实用户研究，参与者模拟行动受限状态，结果显示 E-MPC 能改善用户体验，同时保持任务成功。

- **核心价值：** 家庭康养机器人不是越自动越好。对老人、病患和行动受限用户来说，尊严、参与感和控制感同样重要。未来家庭机器人产品必须把“人机关系”当成控制目标，而不是只看任务完成。

### 3. [MuseVLA：家庭机器人需要听觉、温度、雷达等多模态感知，不应只靠 RGB](https://arxiv.org/abs/2606.17598)

**摘要：** `MuseVLA` 提出一种自适应多模态感知 VLA 模型，把新型传感器作为按需调用的工具。给定任务指令和视觉上下文，模型先生成 sensor token 和目标描述，选择需要调用的传感模态及关注对象；再把传感器测量转换为 grounded sensor image，作为统一中间表征输入 VLA。作者还提出数据合成管线，用 grounded sensor images 增强现有 RGB 视频数据，以降低多传感机器人数据采集成本。真实机器人实验覆盖温度引导取放、声音驱动找物、雷达辅助隐藏物体检索等任务，MuseVLA 平均成功率达 80.6%，显著优于 RGB-only 和多传感基线。

- **核心价值：** 家庭场景里很多关键信息看不见：水杯冷热、手机声音、被遮挡物体、灶台风险。多模态感知会成为家庭机器人从“看见”走向“理解物理生活”的关键能力。

### 4. [EBench：不要只看一个成功率，家庭移动操作需要能力画像](https://arxiv.org/abs/2606.18239)

**摘要：** `EBench` 是一个用于诊断通用移动操作策略的仿真基准，包含 26 个多样且具有挑战性的操作任务，并沿 5 个能力维度和 4 个泛化维度进行标注。作者评估 π0、π0.5、XVLA、InternVLA-A1 等通用操作模型，发现即便整体成功率相近，不同模型的能力画像差异明显：π0.5 具备最高测试成功率和最佳 train-test retention，InternVLA-A1 在移动操作上占优但在灵巧任务上崩溃，XVLA 则在另一组原子技能上表现更强。

- **核心价值：** 家庭机器人任务跨度极大：移动、抓取、开合、整理、递送、避人、对话。只用一个总成功率评价模型，会掩盖关键短板。EBench 这类能力画像评测更适合家庭机器人选型和迭代。

### 5. [FlowMaps：家庭不是静态地图，物体会随人的习惯长期移动](https://arxiv.org/abs/2606.20209)

**摘要：** `FlowMaps` 用 latent flow matching 建模家庭动态物体未来位置的多模态分布。家庭机器人不仅要理解 3D 空间布局，还要推理人在日常活动中如何移动物体。FlowMaps 学习物体之间和时间演化的隐式依赖，基于过去人类交互预测物体可能在哪里，并在仿真与真实环境的动态 Object Navigation 任务中进行验证。超过 600 个 episode 的实验显示，FlowMaps 超过现有方法。

- **核心价值：** 家庭机器人找不到东西，很多时候不是感知失败，而是没有理解人的生活规律。长期物体动态模型会成为家庭找物、整理和提醒服务的核心基础设施。

### 6. [BestMan：用自动场景生成和统一中间件降低家庭移动操作部署成本](https://arxiv.org/abs/2606.18646)

**摘要：** `BestMan` 面向家庭移动操作任务，提出可扩展 real-to-sim-to-real 平台。其 Automated Scene Generation（ASG）模块可从真实观测重建逼真仿真场景；仿真引导的任务形式化和技能学习架构支持混合技能策略的大规模评估；Hardware-agnostic and Unified Middleware（HUM）则面向异构移动操作机器人，提升 sim-to-real 迁移兼容性。

- **核心价值：** 每个家庭都是非标场景，逐户调参不可持续。BestMan 的意义在于把真实家庭观测转成可训练、可评估、可部署的工程流程，帮助家庭机器人从实验室走向更多住宅和康养空间。

### 7. [真实场景 + 合成数据生成：家庭视觉模型需要跨越仿真到真实域差距](https://arxiv.org/abs/2606.20272)

**摘要：** `Efficiently Linking Real Scenes with Synthetic Data Generation` 讨论了认知机器人和计算机视觉应用中，如何把真实场景与合成数据生成高效连接。论文指出，语义环境分析、6D 位姿估计和抓取姿态估计等能力，是工业和家庭机器人应用的重要基础，但这些能力需要更强的数据生成方法与 AI 架构共同解决精度、可扩展性和 domain gap 问题。作者介绍了通过训练数据生成连接仿真与真实应用的工作进展。

- **核心价值：** 家庭数据采集受隐私和成本限制，纯真实数据难以覆盖长尾。真实场景与合成数据结合，会成为家庭机器人视觉模型扩展到更多房型、光照和物体组合的关键路径。

## 开源生态

### 1. [ROBOSHACKLES 开放数据：家庭机器人安全压力测试有了公共入口](https://huggingface.co/datasets/YZW00/RoboShackles)

**摘要：** ROBOSHACKLES 数据集已在 Hugging Face 开放，包含 10000 段基于真实 DROID 观测生成的安全关键机器人视频，覆盖直接伤害与间接伤害类别，可用于危险预判、拒绝学习和具身基础模型安全评测。

- **核心价值：** 家庭机器人上线前需要类似汽车碰撞测试的“危险情境压力测试”。ROBOSHACKLES 提供了一个可复用起点，让社区能系统评测模型是否知道“不该做什么”。

### 2. [FlowMaps 开放代码和材料：家庭动态物体图谱进入可复现阶段](https://fra-tsuna.github.io/flowmaps/)

**摘要：** FlowMaps 项目页提供代码与补充材料，展示如何在连续 3D 空间中预测动态物体未来位置的多模态分布，并用于动态 Object Navigation。

- **核心价值：** 未来家庭机器人地图不应只是“房间在哪里”，还应包括“东西通常会被谁移动到哪里”。FlowMaps 有助于把家庭地图升级为动态生活图谱。

### 3. [APOLLO 代码开放：个性化整理强调隐私、低成本和选择性 LLM 调用](https://github.com/PaInt-Lab/APOLLO)

**摘要：** APOLLO 项目代码已开放。其轻量个性化 embedding model 可针对用户-环境对训练，在 CPU 上运行，并通过不确定性估计只在模糊整理决策时调用 LLM。

- **核心价值：** 家庭机器人不可能把所有家庭偏好都上传云端处理。轻量本地模型 + 选择性大模型辅助，更符合家庭隐私和成本约束。

### 4. [E-MPC 项目页开放：照护机器人开始把“用户参与感”纳入控制框架](https://emprise.cs.cornell.edu/empc)

**摘要：** E-MPC 项目页展示了 engagement-aware human-in-the-loop 框架，用于在照护任务中平衡机器人自主性、用户参与感和用户工作负担。

- **核心价值：** 家庭机器人进入康养陪护后，用户体验不只是 UI，而是控制系统的一部分。让用户参与但不疲劳，会成为陪护机器人差异化能力。

## 结尾总结

6 月 20 日这期继续深挖家庭机器人，结论更加清晰：家庭机器人不是一个单点产品，而是一套长期服务系统。

它需要 FlowMaps 这样的动态物体记忆，知道物体会随人的习惯变化；需要 BestMan 这样的 real-to-sim-to-real 平台，把真实家庭转成可训练和可验证场景；需要 ROBOSHACKLES 这样的安全数据，提前学会拒绝危险动作；需要 APOLLO 这样的个性化整理能力，尊重每个家庭的偏好；需要 E-MPC 这样的照护交互机制，让用户保持参与感和控制感；还需要 MuseVLA 这样的多模态感知，理解声音、温度、遮挡和隐藏物体。

因此，家庭机器人最先落地的未必是“全能家务机器人”，而可能是围绕康养、找物、取放、提醒、辅助进食、整理和安全巡检的一组可收费服务。谁能把这些服务做成可验证、可迭代、可复制的闭环，谁才真正进入家庭机器人深水区。

**互动问题：** 如果家庭机器人明年只能先做好一个功能，你希望它优先做好哪一个：安全巡检、老人陪护、找物取物、收纳整理、辅助进食，还是做饭备餐？欢迎留言说说你的选择。
