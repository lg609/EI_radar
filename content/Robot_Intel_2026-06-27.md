# 具身智能情报前沿｜ABC-130K 把双臂操作数据栈开源

**作者：具身视界** · 2026.06.27

> 今天最值得关注的变化，是机器人操作研究正在从“单个模型刷榜”走向“数据、硬件、仿真、训练和评测全栈开源”。ABC-130K 释放 3,553 小时、134,806 条双臂遥操作轨迹，覆盖 195 个任务；VibeAct、LA4VLA、E-TTS 和 HumanoidUMI 则分别从触觉、语言动作先验、测试时扩展和无机器人示范采集补齐操作落地链路。具身智能操作的竞争，正在变成可复现数据工程与真实评测工程的竞争。

---

## 今日重磅

### [ABC-130K 发布：3,553 小时双臂操作数据，把行为克隆从“私有配方”推向开放工程](https://arxiv.org/abs/2606.27375)

**摘要：** 6 月 25 日提交的 `Scalable Behavior Cloning with Open Data, Training, and Evaluation` 是今天最值得看的具身操作基础设施进展。UC Berkeley、MIT、Amazon FAR、XDOF、CMU 等团队发布 ABC 全栈：核心数据集 ABC-130K 包含 134,806 条双臂遥操作轨迹、3,553 小时真实交互数据，覆盖 195 个任务，任务类型包括 pick-and-place、折叠、交接、插入、工具使用和装配；同时开放可访问硬件方案、训练基础设施、MuJoCo 仿真管线、400 小时 sim-teleop 数据和超过 100 小时真实机器人评测日志。更关键的是，它不是只发布数据，而是给出可验证的操作学习闭环：团队比较 DiT 与 VLA 架构，释放 ABC-DiT 与 ABC-VLA，并证明仿真评测与真实表现高度相关，strict success 相关系数 r=0.85，task progress 相关系数 r=0.91。系统还能完成折纸箱、从钱包中取信用卡、整理书包等接触丰富、长程、双手协同任务；被动 leader arms 的 DAgger 介入方案让纸箱折叠任务平均进度从 24% 提升到 85%。

- **来源：** arXiv / ABC 项目页
- **核心价值：** 这是今天的数据相关报道。ABC-130K 的意义不只是“又一个大数据集”，而是把双臂操作的数据采集、仿真代理评测、模型训练、真实评测和干预式数据回流一起开源；这会显著降低社区复现高质量机器人操作策略的门槛，也会倒逼商业团队把数据质量、评测协议和闭环采集能力拿到台面上比较。

## 行业新闻

### 1. [ABC 项目开放完整操作学习栈：数据、硬件、训练、仿真和评测日志同时释放](https://abc.bot/)

**摘要：** ABC 项目页显示，团队不仅发布 ABC-130K 数据，还开放硬件设置、训练代码、推理优化、仿真数据、Blender 重渲染管线和真实评测 rubrics。对具身操作社区来说，这比单独开放 checkpoint 更重要，因为很多机器人论文难以复现的瓶颈并不在模型，而在数据格式、遥操作硬件、评测标准和真实机器人试验成本。

- **来源：** ABC 项目页
- **核心价值：** 机器人操作正在进入“全栈可审计”阶段：谁能把数据、代码、硬件和评测一起公开，谁就更容易成为社区事实标准。

### 2. [ABC-DiT 与 ABC-VLA 对比：真实操作评测开始成为模型架构选择的硬指标](https://abc.bot/)

**摘要：** ABC 团队比较了 Diffusion Transformer 和 Vision-Language-Action 两类策略。ABC-DiT 采用约 1.93B 的 DiT action head 搭配较小视觉编码器；ABC-VLA 基于 4.3B Gemma 3 backbone 和 45M action head，并用多 diffusion draws 摊薄一次 VLM 前向计算成本。项目报告显示，更大数据规模、更大训练 compute 和更高效推理编译都能改善真实任务表现，ABC-VLA 在单张 5090 上可达 57.2Hz。

- **来源：** ABC 项目页
- **核心价值：** 具身操作模型不再只比较离线 loss，而要比较真实成功率、推理频率、数据扩展性和评测成本；这会让 VLA 与扩散策略的工程优劣更加透明。

### 3. [MMBench2：427 小时、210 任务世界模型数据集，用“幻觉检测”指导机器人补数据](https://arxiv.org/abs/2606.27326)

**摘要：** `Hallucination in World Models is Predictable and Preventable` 发布 MMBench2，包含 427 小时、210 个任务、10 个 domain 的视觉世界模型测试床，并训练 350M 参数世界模型。研究发现世界模型幻觉主要来自数据覆盖不足，并提出 tokenizer round-trip residual、flow instability、inter-seed variance 三类无标签预测信号；在 10 个未见任务上，只用每任务 50 条轨迹进行针对性数据采集，基于幻觉预测的 curiosity 策略可接近专家 / 人类数据采集效果的 90%。

- **来源：** arXiv / MMBench2 项目页
- **核心价值：** 世界模型要服务操作规划，不能只生成“看起来合理”的未来。MMBench2 把幻觉定位为数据覆盖问题，并给出主动补数据方法，对机器人长期部署和在线数据闭环很关键。

### 4. [OctoSense：59 小时八传感器同步数据，推动机器人感知从 RGB-only 走向多模态鲁棒性](https://arxiv.org/abs/2606.27317)

**摘要：** `OctoSense` 发布开放传感平台与数据集，包含 stereo RGB、event camera、LiDAR、thermal、IMU、RTK GPS、CAN / 关节本体感知等八类同步传感器，覆盖 59 小时、2,474 公里驾驶数据，并包含夜间、强眩光、退化传感等场景。其 late-fusion masked autoencoder 在深度、光流、语义分割、ego-motion 等任务上优于图像基础模型，在退化和夜间条件下优势更明显，嵌入式 Orin NX 编码约 112ms。

- **来源：** arXiv / OctoSense 项目页
- **核心价值：** 真实机器人不会永远处在理想光照里。OctoSense 说明未来具身感知基础模型必须吸收热成像、事件相机、LiDAR、IMU 和本体感知，尤其适合户外移动操作、巡检和高可靠服务机器人。

## 前沿论文

### 1. [VibeAct：把振动触觉变成接触与滑移表征，提升接触丰富灵巧操作](https://arxiv.org/abs/2606.27344)

**摘要：** `VibeAct` 关注机器人灵巧操作中视觉常看不到的快速接触事件。团队在灵巧手中嵌入压电麦克风，采集真实振动声学信号，再把动作回放到校准数字孪生中自动标注每根手指的 contact、slip 和 slip magnitude。策略训练时不直接模拟原始音频，而是在仿真中使用同一接触—滑移表征进行强化学习。实验覆盖重抓、手内重定向、插入、旋转等 5 类接触丰富任务，并迁移到真实手臂平台。

- **作者团队：** Yuemin Mao、Uksang Yoo、Jean Oh、Jonathan Francis、Jeffrey Ichnowski
- **来源：** arXiv / 项目页
- **核心价值：** 灵巧操作真正难的部分往往发生在接触瞬间。VibeAct 说明低成本高带宽振动触觉可以绕过“原始触觉难仿真”的问题，转化为可训练、可迁移的接触与滑移中间表征。

### 2. [LA4VLA：先学“语言—动作”先验，减少 VLA 对视觉捷径的依赖](https://arxiv.org/abs/2606.27295)

**摘要：** `LA4VLA` 指出现有 VLA 预训练中，密集视觉—动作监督容易压过稀疏语言—动作信号，导致策略依赖视觉捷径，而不是理解语言如何约束动作。团队将示范轨迹分解为原子动作段，并为每段配对低层动作描述，构造 LA4-33K，共 33K 个 Language-Action episodes，无需额外机器人采集。其 1B 参数 LA4VLA 在仿真和真实任务中均优于对应 VLA 预训练，混合 LA-VLA 预训练最高带来 17.8 和 45.0 个百分点成功率提升。

- **作者团队：** 上海交通大学等
- **来源：** arXiv / GitHub
- **核心价值：** 机器人不是只要“看见物体”就会操作，还要理解“拧、倒、插、推、对齐”等动作语义。LA4VLA 把语言动作先验作为独立数据资产，有助于提升跨场景操作鲁棒性。

### 3. [E-TTS：具身测试时扩展，把推理与动作候选一起闭环迭代](https://arxiv.org/abs/2606.27268)

**摘要：** `E-TTS` 提出 Embodied Test-Time Scaling 框架，面向机器人操作中的推理和动作扩展。它不是只让 VLA 采样多个动作，而是进行 reasoning-action joint sampling，并用 vision-language verifiers 对推理和动作候选成对打分；同时引入 history buffer，让长程任务中的历史上下文参与候选评估。实验覆盖 4 个 benchmark、6 个环境、3 种本体和 4 个基础 VLA，在不额外采集专家数据、不重新训练的情况下，仿真提升最高 33.14%，真实场景提升 26.62%。

- **作者团队：** Wen Ye 等
- **来源：** arXiv / ECCV 2026
- **核心价值：** 具身智能操作不能把推理和控制割裂。E-TTS 显示，在部署端通过历史感知、候选采样、视觉语言验证和反馈迭代，也能显著提升操作成功率。

### 4. [HumanoidUMI：用 VR 与 UMI 式夹爪采集无机器人全身操作示范](https://arxiv.org/abs/2606.27239)

**摘要：** `HumanoidUMI` 解决人形全身操作示范采集成本高的问题。它使用轻量 VR 设备和 UMI-inspired grippers，在没有机器人本体的情况下采集人类关键点轨迹、腕部视角观测和夹爪动作，再训练高层策略预测未来关键点，并重定向为机器人原生全身参考，由 whole-body controller 执行。论文在 5 个真实场景中验证了这种 robot-free 示范对人形全身技能学习的可迁移性。

- **作者团队：** Hongwu Wang 等
- **来源：** arXiv
- **核心价值：** 人形机器人操作数据不能完全依赖昂贵遥操作。HumanoidUMI 把“人类自然示范—关键点预测—全身控制”串起来，是降低人形操作数据成本的重要方向。

### 5. [RelAfford6D：用关系型 6D affordance 图，把语义指令落到可执行约束轨迹](https://arxiv.org/abs/2606.27036)

**摘要：** `RelAfford6D` 面向开放世界操作中的 articulated objects。系统从自由语言指令中推断“交互部件—物理锚点”的语义拓扑，再借助视觉基础模型提升为精确 SE(3) 位姿，并把执行转化为运动学约束满足问题，例如沿 revolute 或 prismatic 物理流形生成轨迹。方法无需训练，并在仿真和真实环境中展示零样本成功率、跨类别泛化和抗扰动闭环重规划优势。

- **作者团队：** Guodong Zhang 等
- **来源：** arXiv
- **核心价值：** 对抽屉、门、旋钮、盖子等结构化物体，纯数据驱动策略容易缺少物理约束。RelAfford6D 提醒我们：操作智能需要语义、几何和运动学约束共同工作。

### 6. [StaKe：用阶段与关键帧辅助监督，修复 VLA 在夹爪事件处的失败](https://arxiv.org/abs/2606.26801)

**摘要：** `StaKe` 发现 VLA 微调中失败常集中在 gripper-event transitions，例如抓住、释放、插入、合上等关键瞬间。它从示范夹爪状态自动派生两个辅助信号：当前操作阶段分类器，以及下一次夹爪事件目标 joint action 的关键帧预测器。该插件不改变基础 VLA 推理循环，在双臂仿真和 Franka 真实机器人任务中分别带来 14% 和 56% 的相对成功率提升，长程任务收益更明显。

- **作者团队：** arXiv 2606.26801 作者团队
- **来源：** arXiv
- **核心价值：** 操作策略的很多失败不是“完全不会”，而是卡在关键事件切换点。StaKe 用低成本结构化监督强化这些转折点，对工业装配、开合、插拔和整理任务很实用。

## 开源生态

### 1. [ABC 代码、数据与仿真管线开放：双臂行为克隆有了可复现实验底座](https://github.com/amazon-far/abc)

**摘要：** ABC 项目页列出 GitHub 代码、Hugging Face 数据集、训练与评测工具。数据包括 ABC-130K 的 134,806 条真实双臂轨迹，以及 400 小时仿真遥操作数据；项目还开放 abcdl 分布式 dataloader，用 MP4 + binary state/action 文件组织 episode，并优化随机帧访问效率。

- **来源：** GitHub / ABC 项目页
- **核心价值：** 这类工具会影响接下来一批操作论文的默认实验设置。对开发者来说，最有价值的是它把“大规模机器人数据如何存、取、训、评”变成了可复用工程。

### 2. [ABC-130K Hugging Face 数据集：195 个双臂任务覆盖折叠、插入、工具使用和装配](https://huggingface.co/datasets/XDOF/ABC-130k)

**摘要：** ABC-130K 数据集覆盖 195 个任务、7 类 manipulation primitive，episode 时长从约 7 秒到 469 秒不等。任务包括放置螺丝刀、折叠衣物、装盘、拧瓶盖、取信用卡、折纸箱、整理书包等，既有短程抓放，也有长程、多阶段、接触密集的双手协同操作。

- **来源：** Hugging Face / ABC 项目页
- **核心价值：** 这会补齐过去开放数据集中“单臂、短程、桌面玩具任务”过多的问题。双臂、长程、日常物品操作数据，是人形上半身与服务机器人真正需要的训练材料。

### 3. [MMBench2 开源：世界模型幻觉检测可作为主动采集信号](https://github.com/nicklashansen/mmbench2)

**摘要：** MMBench2 项目页显示，论文、代码、数据集、模型和 live demo 均开放。它不仅用于评测世界模型，还提供在线幻觉预测指标，能在模型 rollout 时标出高风险区域，并把这些区域作为 targeted data collection 的目标。

- **来源：** GitHub / 项目页
- **核心价值：** 对机器人世界模型来说，最重要的不是生成视频有多像，而是能否知道自己在哪里不可靠。MMBench2 把“模型不知道什么”转化为数据采集策略。

### 4. [OctoSense 开放平台与数据：多传感器机器人感知开始社区化](https://github.com/anthonytec2/OctoSense)

**摘要：** OctoSense 开放机械 CAD、传感器安装、同步电路和数据处理工具，数据集也在 Hugging Face 发布。其同步平台支持 RGB、event、thermal、LiDAR、IMU、GNSS 和本体数据统一时间线，并提供自然语言检索索引，便于按场景查询片段。

- **来源：** GitHub / OctoSense 项目页
- **核心价值：** 操作机器人进入仓储、园区、户外和夜间场景后，RGB-only 感知会遇到瓶颈。OctoSense 这类开放平台有机会推动多模态机器人感知从少数实验室工程变成可复用社区资产。

## 结尾总结

6 月 27 日这期的主线，是具身智能操作正在补齐“可规模化学习”的工程底座。ABC-130K 把双臂遥操作数据、仿真代理评测、真实评测和 DAgger 干预采集连成开源闭环；VibeAct 让触觉从硬件信号变成可训练的接触—滑移表征；LA4VLA 让语言动作先验独立出来；E-TTS 让部署端通过推理、动作候选和历史上下文继续变强；HumanoidUMI 则降低了人形全身操作示范采集门槛。

可以下一个判断：**具身智能操作的下一轮分水岭，不是单个 VLA 模型会不会抓杯子，而是谁能持续生产高质量操作数据、低成本发现失败、用真实评测闭环验证，并把这些能力变成可复用基础设施。** 当数据、硬件、触觉、仿真、评测和部署干预开始标准化，机器人操作才真正具备从实验室走向规模部署的条件。

## 值得分享

1. **双臂操作数据进入开源大规模阶段：** ABC-130K 发布 3,553 小时、134,806 条真实双臂遥操作轨迹，覆盖 195 个任务，把操作学习从私有配方推向公开基建。
2. **真实评测正在成为机器人模型硬指标：** ABC 显示仿真评测与真实操作进度相关系数达 r=0.91，未来模型优劣要看真实任务、推理频率和数据闭环，而不只是离线 loss。
3. **灵巧操作离不开接触信号：** VibeAct 用压电麦克风把振动触觉转成接触与滑移表征，说明下一代灵巧手竞争会同时发生在传感器、数据标注和策略学习里。
