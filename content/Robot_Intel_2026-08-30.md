# 具身智能情报前沿｜基础研究转向世界模型

**作者：具身视界** · 2026.08.30

> **一句话判断：** 具身智能的基础研究正在从“让机器人听懂指令并输出动作”，转向“让机器人理解物理世界、预演行动后果、从失败中修正策略”。
> **今日看点：** WRC闭幕信息宣布成立中国电子学会世界模型专家委员会；主论坛观点集中指向数据、算法、算力、神经科学、物理常识和安全治理；Zero-WAM、The Imitator Game、R³、CLAP、WALL-SS等近一周论文把研究焦点压到世界模型、跨本体迁移、模仿评测和机器人推理。
> **影响对象：** 具身大模型团队、机器人本体公司、仿真与数据平台、高校实验室、算力厂商、投资机构和真实场景客户。

---

## 今日判断

1. 具身智能的基础研究主线正在从 VLA 走向 WAM。VLA 可以简单理解为“看见环境、理解语言、预测动作”，WAM 则进一步要求机器人预测“动作会怎样改变世界”。
2. 数据问题开始变得更底层。近一周论文不是单纯扩大机器人遥操作数据，而是在用人类视频、跨本体视频、生成式世界模型和失败轨迹，补足机器人真实数据稀缺的问题。
3. 评测标准正在升级。过去常看成功率和轨迹误差，现在更需要看意图模仿、长程一致性、跨本体泛化、失败识别和真实机器人校准。

## 💥 今日重磅

### [WRC宣布成立世界模型专家委员会，基础研究被摆上产业主桌](https://www.worldrobotconference.com/news/3616.html)

**摘要：** 2026 世界机器人大会闭幕信息中，有一个容易被出货量和新品数量掩盖的信号：大会宣布成立中国电子学会世界模型专家委员会。这个动作的意义不只是新增一个组织，而是把“世界模型”从论文概念、企业路线和展会话题，正式推到产业协同层面。WRC闭幕页同时披露，本届大会发布 44 项新技术新方案、展示 3000 余件产品、首发新品 311 件，并发布《2026年人形机器人产业发展报告》等成果。这些信息放在一起看，说明具身智能的竞争已经不是单点算法突破，而是基础研究、数据基础设施、仿真评测、本体平台和场景需求之间的系统工程。

为什么世界模型值得放在“今日重磅”？因为机器人要进入真实环境，只会根据当前画面输出动作是不够的。它必须理解物体会不会滑落、碰撞会不会发生、开门以后视角会怎样变化、错误动作会带来什么后果。WRC主论坛观点也在强调同一件事：具身智能迈向“GPT时刻”需要数据、算法和算力协同跃迁，视觉模型、世界模型和 VLA 模型都依赖更强训练集群、物理仿真、合成数据和虚实迁移。对本体公司来说，世界模型不是锦上添花，而是减少真机试错、提升长程任务可靠性、降低部署成本的基础研究抓手。

- **来源：** 2026 世界机器人大会官网
- **核心价值：** 世界模型正在从研究方向升级为产业公共议题，未来会直接影响机器人训练、仿真、评测和场景交付。
- **具身视界判断：** 具身智能的下一阶段瓶颈不只是“动作模型不够强”，而是机器人缺少可验证的物理世界预判能力；谁能把世界模型和真实机器人闭环打通，谁就更接近规模化。

### 4. 基础研究主线拆解

| 研究问题 | 最近信号 | 为什么重要 |
|---|---|---|
| 世界模型 | WRC成立世界模型专家委员会，WALL-SS、CLAP密集发布 | 让机器人在行动前预测后果，减少真机试错 |
| 跨本体迁移 | Zero-WAM、CLAP都在处理人类视频或多机器人数据 | 解决每换一个机器人就重训一遍的问题 |

| 机器人推理 | R³训练VLM用自然语言推理指导低层策略 | 让长程操作具备分解、检查和纠错能力 |

这张表的结论很直接：基础研究正在从“动作预测”上移到“世界理解”，同时向下连接数据采集、仿真评估和真实控制。

## 📑 前沿论文

### 1. [Zero-WAM：用人类视频做机器人任务提示，推动开放任务泛化](https://arxiv.org/abs/2608.26103)

**摘要：** Zero-WAM 提出一种因果视频-动作模型，让机器人通过上下文中的人类视频学习未见任务。论文还构建 HumanGen 数据集，包含 74.2K 个人类-机器人 ICL 配对、覆盖 8.6K 个任务，并用 in-context future chunk prediction 训练目标减少模型在已见任务上走捷径。作者报告，在 RoboTwin 2.0 的 7 个未见任务中，Zero-WAM 平均成功率达到 47.0%，比最强视频-动作基线高 29.5 个百分点。

- **作者团队：** Robbyant、香港科技大学（广州）等
- **来源：** arXiv
- **核心价值：** 数据相关报道：人类视频正在成为机器人泛化训练的重要数据入口，能够缓解真实机器人配对数据稀缺。

### 2. [The Imitator Game：机器人模仿评测从动作预测走向意图理解](https://arxiv.org/abs/2608.22301)

**摘要：** The Imitator Game 提出四级模仿基准 L0-L3，逐步拉大人类示范和机器人执行场景之间的差异，用来判断模型何时不再能靠轨迹复刻解决问题。论文配套 IG-10K 数据集，覆盖 20,000+ paired episodes、50+ tasks、6 domains，并提供 Imitator Arena 做盲测式人类评估。结果显示，9 个先进模型在 L0-L2 相对稳定，但到 L3 意图级功能替代时明显崩塌。

- **作者团队：** Xunzhe Zhou、Yiyang Cai、Yanchao Yang 等
- **来源：** arXiv
- **核心价值：** 具身智能要从“像人一样动”走向“像人一样理解任务目的”，评测基准必须跟着升级。

### 3. [R³：让机器人用自然语言推理指导长程操作](https://arxiv.org/abs/2608.26053)

**摘要：** R³ 研究的问题是：大模型的自然语言推理能否真正帮助机器人操作。论文把现成视觉语言模型训练成 robotic reasoner，先用专家推理轨迹做中训练，再用离线动作数据中的 rubric-based reinforcement learning 进行改进。实验覆盖 Language Table 和双臂杂货打包仿真任务，结果显示 R³ 在探索和未见任务泛化上优于只看指令的模仿学习基线。

- **作者团队：** Lehong Wu、Yuxiao Qu、Zackory Erickson、Aviral Kumar 等
- **来源：** arXiv
- **核心价值：** 长程操作不是单步控制问题，机器人需要在执行过程中持续跟踪进度、关系、约束和错误。

### 4. [CLAP：跨本体视频世界模型尝试学习通用物理规律](https://arxiv.org/abs/2608.27406)

**摘要：** CLAP 面向跨本体 action-conditioned video world model，核心问题是不同机器人动作空间不同、人类视频通常没有动作标签，如何仍然从异构视频中学习可泛化的物理规律。论文通过末端执行器位姿、语言指令和 latent actions 统一不同动作空间，并在 DROID、Bridge、双臂 YAM、G1 人形等形态上做实验。作者强调，CLAP 开源代码和模型。

- **作者团队：** Kechen Liu、Ola Shorinwa
- **来源：** arXiv
- **核心价值：** 跨本体世界模型如果成立，将显著降低机器人数据复用成本，让不同机器人共享一部分物理经验。

## 💻 开源生态

### 1. [CLAP开源仓库：把多机器人相机视角压进统一输入形态](https://github.com/omni-CLAP/clap)

**摘要：** CLAP 的 GitHub 仓库展示了跨本体视频世界模型的工程细节，例如将不同机器人多相机帧统一 resize 到 192x320，并按固定形状堆叠输入；仓库说明也提到适配 bimanual YAM 和 G1 humanoid 等平台。对开发者来说，这类工程约束比论文标题更关键，因为跨本体训练首先要解决输入格式和动作空间不统一。

- **来源：** GitHub
- **核心价值：** 开源生态正在把“跨本体”从概念落到数据格式、相机堆叠、动作表示和微调流程。

### 2. [WALL-SS仓库：长程世界模型先发布论文和项目页，代码仍待释放](https://github.com/X-Square-Robot/wall-ss)

**摘要：** 自变量机器人 WALL-SS 仓库已发布项目页和论文信息。README 显示，WALL-SS 是面向 action-controllable、long-horizon robotic simulation 的生成式世界模型，采用粗到细的 next-scale autoregression，把观测和动作交错建模为因果序列。仓库当前显示论文已发布，训练和推理代码尚未释放。

- **来源：** GitHub
- **核心价值：** 这是值得跟踪的开源信号，但现阶段更适合作为研究路线观察，不应误读为完整可复现代码已经发布。

### 3. 数据相关报道：基础研究正在争夺“可复用数据”

| 数据类型 | 代表工作 | 对机器人基础研究的价值 |
|---|---|---|
| 人类视频 | Zero-WAM / HumanGen | 用更便宜、更丰富的人类示范补足机器人数据稀缺 |
| 配对模仿数据 | The Imitator Game / IG-10K | 衡量机器人是否理解意图，而不是只复刻轨迹 |
| 跨本体视频 | CLAP | 让不同机器人、本体和摄像头配置共享物理经验 |
| 生成式轨迹 | WALL-SS | 用可控世界模型做策略评估和长程仿真 |

具身视界判断：数据相关报道的重点正在变化。过去大家问“机器人数据有多少小时”，现在更要问“这些数据能不能跨任务、跨本体、跨场景复用”。

## 结尾总结

今天这篇的主线不是某个机器人又完成了一个动作，而是具身智能基础研究正在重新定义“智能”本身：机器人要会预测世界、理解意图、跨本体迁移、在长程任务中推理并纠错。WRC把世界模型推到产业组织层面，近一周论文则把数据、评测和开源工程继续往下压实。下一步最值得看的是：这些世界模型能不能从视频预测，真正走到低成本真机部署和可复现的长期作业。
