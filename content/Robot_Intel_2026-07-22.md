## 📚 前沿论文

### 1. [MIDAS Hand：低成本开源触觉灵巧手给出 16 自由度与 283 个触觉 taxel](https://arxiv.org/abs/2607.14487)

**摘要：** 7 月 16 日提交的 MIDAS Hand 面向可复现触觉灵巧操作硬件。论文给出一只 700g、人手尺度、低阻抗直驱仿人灵巧手，包含 16 总自由度、13 主动自由度、283 个三轴触觉 taxels，BOM 成本低于 3000 美元，并支持 3D 打印、3 小时内组装、控制和触觉 Python API、仿真模型、重定向和遥操作流程。

- **来源：** arXiv / 项目页
- **核心价值：** MIDAS Hand 把灵巧手从“昂贵实验室硬件”推向可复现研究平台；触觉、低成本和完整软件栈会直接影响操作数据生产速度。

### 2. [Industrial Dexterity Benchmark：工业灵巧操作开始用硬件软件基准说话](https://arxiv.org/abs/2607.14021)

**摘要：** 7 月 15 日提交的 Industrial Dexterity Benchmark 面向工业灵巧操作，设置数据中心线缆管理、汽车线束和齿轮箱装配等任务板，并提出 DAG-ROS 和 AG-iDP3 等学习框架。在数据中心线缆任务中，多视角 RGB + R3M 的 multimodal Diffusion Policy 达到 78% 抓取并插入综合成功率，高于单相机 RGB DP 的 36%，每个任务阶段约需 100 条遥操作示范。

- **来源：** arXiv
- **核心价值：** 数据相关报道：灵巧手要进入工厂，必须用任务数据、遥操作示范数量和成功率证明价值；工业基准会淘汰只会展示简单抓取的方案。

### 3. [Towards Artificial Nerves：光纤触觉传感把“人工神经”引入机器人触觉](https://arxiv.org/abs/2607.15746)

**摘要：** 7 月 17 日提交的论文提出 OptiTac，借鉴人体机械感受器到神经的结构，用软皮肤上的机械 pin 配对 optical fiber artificial nerve，将触觉信息从传感表面导出，同时保持较高空间分辨率。论文强调把触觉信号当作图像处理，用可解释方法推断接触位置、大小和形状。

- **来源：** arXiv
- **核心价值：** 灵巧手的下一步不只是更多自由度，而是分布式触觉；能解释接触状态，才可能支撑可靠抓取和安全交互。

### 4. [Handroid：一套 27 自由度机电身体在灵巧手和桌面人形之间重构](https://arxiv.org/abs/2607.16187)

**摘要：** 7 月 17 日提交的 Handroid 把灵巧手和人形机器人放进同一可重构平台。论文介绍一个 0.33m、2.05kg、27 自由度桌面尺度双形态机器人，同一机电身体可作为 20 自由度仿人灵巧手，也可重构为包含头、臂、腿的人形形态，并支持手部遥操作、灵巧抓取、手内操作、人形运动和长时序任务。

- **来源：** arXiv
- **核心价值：** Handroid 的信号是：灵巧手和人形本体不应割裂研发，跨形态学习可能成为低成本验证接触操作和整机控制的新路径。

## 🧩 开源生态

### 1. [HandUMI 软件 7 月 22 日更新：双臂灵巧操作采数接口继续活跃](https://github.com/robonet-ai/handumi-sw)

**摘要：** GitHub API 显示，robonet-ai/handumi-sw 7 月 22 日有推送，星标约 36。项目描述为用于 synchronized bimanual data collection，并可 retargeting to any bimanual robot，包含 calibration、QA、replay 和 teleoperation。它解决的是灵巧操作数据从人手、双臂到机器人本体之间的同步和迁移问题。

- **来源：** GitHub
- **核心价值：** 数据相关报道：灵巧手硬件没有操作数据就无法训练策略；HandUMI 这类采数工具会成为灵巧操作模型迭代的底层入口。

### 2. [HandUMI 硬件 7 月 22 日更新：无机器人在环采集双臂操作数据](https://github.com/robonet-ai/handumi-hw)

**摘要：** GitHub API 显示，robonet-ai/handumi-hw 7 月 22 日有推送，星标约 39。项目描述为 hand-worn variant of UMI，可在没有机器人在环的情况下采集 bimanual manipulation data，并面向任意 parallel-jaw gripper 做模块化设计。它把采数从固定机器人工作站扩展到穿戴式采集。

- **来源：** GitHub
- **核心价值：** 数据相关报道：如果灵巧手数据只能靠昂贵真机慢慢采，扩展会很困难；穿戴式采集能降低双臂操作数据生产门槛。

### 3. [AnyDexRetarget 7 月 20 日更新：多灵巧手重定向成为工程刚需](https://github.com/qqsq12321/AnyDexRetarget)

**摘要：** GitHub API 显示，qqsq12321/AnyDexRetarget 7 月 20 日有推送，星标约 49。项目描述为面向 multiple dexterous hands 的高精度手部姿态重定向，支持 Vision Pro、Quest 3、camera 等输入。对 WAIC 这类多本体、多灵巧手共场展示来说，重定向是把人类示范转到不同手部硬件上的关键接口。

- **来源：** GitHub
- **核心价值：** 灵巧手生态越多样，重定向越重要；否则每换一只手都要重做采数和控制适配，成本会迅速上升。

## 结尾总结

7 月 22 日的主线可以概括为：WAIC 把灵巧手放进了一个可以横向比较的产业窗口。官方展商接口显示，多家灵巧手、人形本体、外骨骼和人机交互企业集中在 H3；同期论文和开源项目则把问题推进到触觉 taxel、工业任务成功率、遥操作示范数量、重定向和穿戴式采数。真正值得关注的不是哪只手最像人，而是哪只手能稳定产生数据、感知接触、适配本体并完成真实任务。

> 💬 如果你在 WAIC 现场看灵巧手，你会优先问什么：自由度、抓取力、触觉数量、寿命、成本，还是能不能采集高质量操作数据？
