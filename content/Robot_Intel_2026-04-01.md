## 📰 行业新闻

### 1. [RoboForce 融资 5200 万美元：户外机器人开始围绕“数据飞轮 + 规模制造”构建商业闭环](https://www.therobotreport.com/roboforce-raises-52m-to-commercialize-its-titan-robot/)

**摘要：** RoboForce 本周宣布完成 5200 万美元融资，累计融资达到 6700 万美元，并明确把资金用于三件事：强化机器人基础模型、加速数据飞轮、扩大 Titan 商业化与制造能力。其 Titan 是面向户外高强度场景的双臂移动操作平台，强调高负载与高精度并存（公开信息提到最大负载 40kg），目标覆盖光伏、物流、矿业、制造等多行业。值得关注的是，公司反复强调“真实数据 + 仿真数据”联合策略，并把“数据效率”作为核心竞争力。因为户外场景的光照、天气、地形变化大，数据采集成本高，所以谁先建立稳定的数据生产和模型迭代闭环，谁更可能率先跨过规模化部署门槛。

- **来源：** The Robot Report
- **核心价值：** **这是一条典型“数据生产与数据飞轮”信号，意味着户外具身智能竞争重心正从单机能力转向数据效率与制造效率的联动。**

### 2. [北京“机器人学校”持续扩展训练场：真实场景数据采集正变成固定基础设施](https://english.news.cn/20260330/43016a131096419b943039dd212f8ff2/c.html)

**摘要：** 新华社 3 月 30 日报道，北京首钢园机器人数据训练中心在工业制造、商业服务与家庭等场景持续开展动作数据采集。公开报道显示，采集员通过高频重复任务生成大规模运动数据，并结合动作捕捉技术提升模型对精细控制的学习效率。这类“训练场基础设施化”的变化很关键：具身模型不再依赖零散演示，而是逐步形成可持续的数据供给链。因为数据采集能力一旦标准化，模型团队与机器人整机团队就能围绕统一数据协议和评测流程持续迭代，最终缩短从实验到部署的周期。

- **来源：** 新华社（English）
- **核心价值：** **训练场基础设施化正在把“数据”从项目资源变为长期产能，这是具身智能规模化落地的慢变量。**

## 📑 前沿论文

### 1. [CARLA-Air：统一空地仿真底座，面向具身智能的数据构建与协同训练](https://arxiv.org/abs/2603.28032)

**摘要：** 该论文于 3 月 30 日提交 arXiv，核心贡献是把 CARLA（地面交通仿真）与多旋翼飞行仿真能力放进同一 Unreal 进程，避免跨仿真桥接带来的时空不同步问题。作者声称平台保留 CARLA 与 AirSim 的 Python API 以及 ROS 2 接口，支持在统一物理时钟下同步采集最多 18 路传感数据，并覆盖空地协同、具身导航、VLA 任务、多模态感知与强化学习训练等场景。对研究和工程都重要：因为它把“仿真训练”“多机器人协同”“数据构建”放在同一基础设施中，所以可以减少重复集成成本，提高跨平台实验可复现性。

- **作者团队：** Tianle Zeng, Hanxuan Chen, Yanci Wen, Hong Zhang
- **来源：** arXiv（cs.RO，2026-03-30）
- **核心价值：** **这是“数据基础设施”层面的进展：统一仿真与多模态同步采集能力，会直接影响后续具身模型训练效率与评测一致性。**

### 2. [RAD-LAD：规则规划与语言规划融合，推动实时可解释自动驾驶决策](https://arxiv.org/abs/2603.28522)

**摘要：** RAD-LAD 于 3 月 30 日提交 arXiv，提出将规则规划器（RAD）与语言动作规划器（LAD）组合的混合方案：LAD 在单次前向中给出实时动作规划，并可输出文本化推理；RAD 则提供规则约束下的稳定机动。论文报告 LAD 在延迟上相较既有驾驶语言模型约降低 3 倍，同时在 nuPlan Test14-Hard 与 InterPlan 上达到高水平表现。其意义在于：因为纯规则方案难覆盖开放环境，纯学习方案又存在可控性压力，所以“规则 + 学习”混合路线正在成为具身系统进入高安全场景的现实折中。

- **作者团队：** Anurag Ghosh, Srinivasa Narasimhan, Manmohan Chandraker, Francesco Pittaluga
- **来源：** arXiv（cs.RO，2026-03-30）
- **核心价值：** **具身决策系统正在从“二选一”走向混合架构，这会加速模型进入对实时性与可解释性要求更高的产业场景。**

## 💻 开源生态

### 1. [CarlaAir 开源发布：空地一体具身智能基础设施进入社区可复用阶段](https://github.com/louiszengCN/CarlaAir)

**摘要：** 与论文同步，`CarlaAir` 在 GitHub 开源并快速获得 206 Stars。项目定位不是单一任务算法，而是“空中机器人 + 地面机器人 + 统一世界 + 统一接口”的基础设施层能力，强调兼容 CARLA/AirSim 原生 API 和 ROS 2，便于研究团队直接迁移现有代码。对开源生态而言，这类仓库的价值在于减少重复造轮子：团队可以把精力从环境胶水代码转向策略训练、评测指标和数据闭环本身。因为当底座统一后，跨机构协作与结果复现都会明显改善。

- **来源：** GitHub
- **核心价值：** **开源社区开始把“仿真与数据底座”工程化，这比单点模型开源更能提升行业整体迭代速度。**

## 🏢 机器人公司情报

### 1. [Boston Dynamics 与 Google DeepMind 重启合作：新一代 Atlas 明确走向“产品化 + 基础模型”路线](https://www.therobotreport.com/boston-dynamics-google-reunite-on-next-gen-atlas-humanoid/)

**摘要：** The Robot Report 近期披露，Boston Dynamics 与 Google DeepMind 在 CES 2026 公布合作，计划用 Gemini Robotics 基础模型增强新一代 Atlas 的智能能力。报道同时提到 Atlas 产品化版本的关键参数和部署节奏：例如 56 自由度、最大负载约 110 磅（约 49.8kg）、IP67 等，并给出后续在 Hyundai 场景扩展与训练中心建设规划。对行业来说，这一动态的关键不只是“再合作”，而是头部硬件公司开始把基础模型能力写进量产与服务体系。因为只有当模型能力、现场数据回流和运维体系一起设计，人形机器人商业化才可能从样机阶段走向稳定交付。

- **来源：** The Robot Report
- **核心价值：** **人形赛道正在进入“硬件量产能力 + 基础模型能力 + 数据回流能力”的三维竞争。**

### 2. [Humanoid 与 SAP 完成真实产线 PoC：Agentic AI 开始接入企业系统驱动实体机器人](https://www.therobotreport.com/humanoid-completes-live-hmnd-poc-sap-martur-fompak/)

**摘要：** HMND 与 SAP、Martur Fompak 的联合 PoC 显示，企业侧 AI agent 已经可以把任务直接下发给实体机器人执行仓储拣选流程。公开信息显示，该 PoC 在真实生产环境中完成了“接收任务—自主导航—取放周转箱—循环执行”的闭环，并给出了 8kg 双臂负载能力等工程细节。它的意义在于，具身智能不再只比机器人动作能力，而是要打通企业业务系统、流程编排和审计要求。因为企业客户最终采购的是“可接入流程的执行系统”，不是单台会动的机器人。

- **来源：** The Robot Report
- **核心价值：** **公司竞争焦点正在从“机器人能力展示”转向“企业系统集成深度”，这会直接决定商业化转化速度。**
