## 字段写作指引

- 标题：`具身智能情报前沿｜亮点事件简述`，亮点事件取当天主条的核心信息，20 字以内；日期放在作者行，不出现在标题中。
- 标题优先使用这三类写法：`公司 / 机构名 + 关键动作 + 数字 / 结果`、`技术 / 数据路线 + 变化方向`、`多地 / 多家 / 顶尖机构 + 集体动作`。
- 避免空泛标题，例如“行业开始爆发”“资本押注未来”这类没有主体、动作和信息增量的写法。
- 今日重磅：整篇唯一的深度展开，250-450 字，必须包含"发生了什么、为什么重要、影响谁"三层，并尽量让它代表当天最清晰的一条行业主线。
- 导语：使用三行速读，不要泛泛罗列新闻。
- 快报摘要：不能只复述事实，至少包含事件 + 背景 + 意义。
- 核心价值：写成可引用、可传播的判断句，而不是重复摘要。
- 数据：保留融资金额、性能指标、数据规模、模型版本、合作方等关键数值。
- 因果：尽量显式写出"这意味着什么""为什么现在值得关注"。
- 同一篇文章里的行业新闻、论文、开源、公司动态，尽量共同支撑同一主线，不要为了分栏硬塞弱相关条目。
- 关键词索引：按公司 / 技术 / 产品分组，与正文术语保持一致，便于搜一搜收录。
- 值得分享：3 条要点语言要简洁有力，适合直接复制到朋友圈；避免专业黑话，普通读者也能理解。
- 日报总条目建议 8-10 条，目标正文长度 3,500-4,800 字；重大事件可放宽，但不要用弱条目凑数。
- 每篇至少出现一次 `具身视界判断：`。
- 当有 3 个以上同类对象时，优先使用 Markdown 表格。
- 表格后必须写 1-2 句结论。
- 术语首次出现时尽量补一句人话解释。

## 周报写作指引

- 周报文件名：`D:\RobotGPT\content\Robot_Weekly_YYYY-WW.md`。
- 周报覆盖周一至周日；如果用户指定日期范围，以用户指定为准。
- 周报不是 7 篇日报拼接，必须做归纳、对比和判断。
- 周报至少 2 条数据相关报道，并在“趋势雷达”或“开源与数据”中明确体现。
- 周报目标正文长度 4,500-6,500 字，正文条目建议 10-14 条。
- 周报必须优先使用至少 1 个 Markdown 表格。
- 周报必须明确“本周真正变化是什么”，并说明与上周或近几天相比的新增量。

## 质量检查清单

- 所有链接真实可访问。
- 所有内容在最近 7 天内。
- 已检查近 10 天历史日报，避免重复重点主题。
- 标题格式为`具身智能情报前沿｜亮点事件简述`，不含日期；日期在作者行。
- "今日重磅"已选出并展开到 200 字。
- 导语已使用三行速读。
- 已包含 `今日判断` 或周报 `本周判断`。
- 已包含至少一次 `具身视界判断：`。
- 各板块条目基本围绕同一主线展开，没有明显“拼盘感”。
- 普通条目也有信息密度，不是空泛一句话。
- 有 3 个以上同类对象时，已优先使用表格或说明为什么不用表格。
- 文末包含"关键词索引"和"值得分享"两个段落。
- 最终 Markdown 不含 HTML 标签、占位符、注释说明或内部工作痕迹。
