# 标签体系

## 目标

统一正文标签、关键词索引、选题池和复盘口径，避免同一概念反复换叫法。

## 一级标签

日报正文中的快报标签只使用以下 5 个：

| 标签 | 适用内容 | 例子 |
|------|----------|------|
| `[资本与政策]` | 融资、政策、标准、产业园、交易所、监管、联盟 | 融资、数据交易、地方政策 |
| `[公司与产品]` | 公司动态、产品发布、订单、合作、商业化 | 新机器人发布、客户合作 |
| `[技术路线]` | 模型架构、控制方案、世界模型、推理效率 | VLA、MoE、快慢双系统 |
| `[数据与评测]` | 数据集、数据工厂、benchmark、评测基准、采集系统 | 数据集开源、benchmark 发布 |
| `[开源生态]` | GitHub 项目、开源框架、工具链、版本更新 | LeRobot、Isaac Teleop |

## Topic 编号

选题池、持续追踪和复盘统一使用以下编号：

| 编号 | Topic | 说明 |
|------|-------|------|
| `T01` | 数据采集与数据工厂 | 数据生产、无本体采集、外骨骼、数据工厂 |
| `T02` | 模型与 VLA | 具身基础模型、VLA、世界模型、多模态对齐 |
| `T03` | 控制、小脑与运动规划 | 实时控制、动作分块、运动规划 |
| `T04` | 灵巧手、触觉与操作 | 灵巧手、插接、装配、触觉闭环 |
| `T05` | 仿真、评测与 benchmark | 仿真平台、评测基准、benchmark |
| `T06` | 机器人芯片与算力平台 | 端侧芯片、算力平台、云边协同 |
| `T07` | 公司、产品与商业落地 | 公司路线、产品、客户、场景 |
| `T08` | 政策、资本与供应链 | 投融资、政策、供应链、产业链 |

## 关键词索引规范

`关键词索引` 固定分成 3 组：

- `公司`
- `技术`
- `产品`

### 公司

写法规则：

- 优先中文名，必要时补英文。
- 同一篇只出现一种主写法。

示例：

- `地瓜机器人 (D-Robotics)`
- `灵初智能 (PsiBot)`
- `智平方 (AI² Robotics)`

### 技术

写法规则：

- 优先标准术语，不混用近义词。
- 第一次出现可以中英双写，后文保持统一。

推荐标准术语：

- `视觉-语言-动作模型 (VLA)`
- `世界模型 (World Model)`
- `仿真到现实 (Sim-to-Real)`
- `混合专家架构 (MoE)`
- `动作分块 (Action Chunking)`
- `数据闭环`
- `触觉闭环`
- `动作重定向`

### 产品

写法规则：

- 保留产品原名或项目名。
- 不把公司名误写入产品组。

示例：

- `RynnBrain`
- `RynnBrain-Bench`
- `Isaac Teleop`
- `Xiaomi-Robotics-0`

## 不建议混用的术语

统一以下表达：

| 不推荐 | 推荐 |
|--------|------|
| 具身大模型 / 机器人大模型 混用 | 根据语境固定为 `具身基础模型` 或 `视觉-语言-动作模型 (VLA)` |
| 数据基地 / 数据工厂 混用 | `数据工厂` |
| benchmark / 评测集 / 测试集 混用 | `benchmark` 或 `评测基准`，二者择一后保持一致 |
| 端侧效率 / 端侧推理效率 / 低延迟 混用 | 按场景拆开，优先 `端侧推理效率` |
| 脑补 / 彩排 / 模拟试错 混用 | 正文优先 `世界模型先模拟再执行` |

## 标题关键词优先级

标题尽量优先使用以下高识别词：

- 公司名
- 模型名
- 产品名
- 明确数字
- 赛道关键词

示例结构：

- `公司名 + 动作 + 明确数字`
- `技术路线 + 结果`
- `benchmark / 数据集 + 行业影响`

## 复盘统计口径

周复盘和月复盘统计时，统一按以下维度聚合：

- 一级 topic 编号
- 快报标签
- 主条关键词
- 收藏模块类型

这样才能看出到底是“哪一类内容”有效，而不是只看到单篇文章标题。
