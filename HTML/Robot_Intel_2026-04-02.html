📰 行业新闻

1. Apptronik 再获 5.2 亿美元融资：Apollo 不只是在扩产，也在补训练与数据采集底座

摘要： The Robot Report 近期披露，Apptronik 新增获得 5.2 亿美元融资，带动其 Series A 总额超过 9.35 亿美元，总融资规模接近 10 亿美元。更值得注意的不是金额本身，而是资金用途被明确指向三个方向：Apollo 产能爬坡、全球商业/试点部署扩展，以及机器人训练与数据采集设施建设。因为 humanoid 赛道真正稀缺的从来不只是本体设计，而是“量产能力 + 持续收集高质量数据 + 快速回流模型”的闭环，所以这笔融资更像是在为 Apptronik 的长期基础设施买单，而不只是为单台机器人买单。

  • • 来源： The Robot Report
  • • 核心价值： 这是一条典型“数据飞轮 / 数据基础设施”融资信号，说明头部资本已经开始把训练设施和数据回流视为 humanoid 商业化的必要前提。

2. Machina Labs 完成 1.24 亿美元 C 轮：AI 制造单元开始从样机走向大规模智能工厂

摘要： Machina Labs 本周宣布完成 1.24 亿美元 C 轮融资，并同步推进其美国大型智能工厂建设。公开信息显示，这座约 20 万平方英尺的工厂计划容纳最多 50 个 RoboCraftsman 单元，面向航空航天、国防和汽车行业生产复杂金属结构件。它的意义在于，机器人和 AI 不再只是辅助制造，而是开始改写制造单元本身的组织方式：从成形、机加、焊接到装配，被放进同一套可软件定义的智能生产基础设施里。因为当制造能力可以像软件一样被部署和扩展，机器人公司的商业模式也会从“卖设备”向“卖产能”靠拢。

  • • 来源： The Robot Report
  • • 核心价值： 机器人资本正在更偏爱“可规模复制的生产基础设施”，而不只是单点自动化项目。

3. RobCo 获得 1 亿美元 C 轮融资：模块化硬件与 Physical AI 平台继续获得工业资本加注

摘要： RobCo 宣布完成 1 亿美元 C 轮融资，用于推进其 physical AI 路线、扩大企业部署和加深美国市场布局。公司对外强调的主线很清楚：把模块化硬件、感知、运动规划和自学习软件堆栈做成一体化平台，并通过 RaaS 方式交付给工厂客户。公开材料提到，其机器人已被用于机床上下料、码垛、点胶与焊接等场景，并在 BMW 等客户环境中落地。它值得关注，因为制造业客户并不想采购一堆割裂的自动化部件，而是更倾向于采购“能持续学习、能快速部署、能反复复用”的完整系统。

  • • 来源： The Robot Report
  • • 核心价值： 工业机器人融资重点正从“单设备能力”转向“平台化交付与持续学习能力”。

4. Konnex 获得 1500 万美元融资：机器人即服务开始尝试从封闭系统走向“像 App 一样被调用”

摘要： Konnex 上周宣布完成 1500 万美元融资，目标是把机器人与 AI 的物理劳动能力做成可签约、可验证、可结算的平台协议。其设想并不局限于卖某一款机器人，而是试图把自主系统纳入类似应用生态的调用框架中，让任务结果验证、支付结算和服务扩展更标准化。虽然这条路仍很早期，但它反映出一个值得留意的方向：当机器人逐步进入真实商业流程后，行业下一步竞争不仅是本体和模型，还包括谁能定义更通用的服务接口与交易规则。

  • • 来源： The Robot Report
  • • 核心价值： 如果机器人要规模进入企业工作流，服务协议和结算层最终会像云服务 API 一样重要。

📑 前沿论文

1. Realtime-VLA V2：把 VLA 从“会做”推进到“能快、能顺、能准地跑在真机上”

摘要： Realtime-VLA V2 于 3 月 27 日提交 arXiv，核心问题不是再造一个更大的 VLA，而是解决真实机器人部署里最容易被忽略却最致命的问题: 执行速度、轨迹平滑性和任务精度能否同时成立。论文提出一套覆盖标定、规划控制与学习方法的工程栈，目标是在真实任务中把 VLA 驱动的机器人运行到接近日常人工操作速度，并逼近轻量机械臂的硬件上限。它值得看，是因为 VLA 过去常被质疑“看起来聪明，但上真机太慢、太抖、太难稳定复现”；而这篇工作等于直接把矛头指向部署层，说明研究重点正在从模型感知理解，转向整机执行效率。

  • • 作者团队： Chen Yang, Yucheng Hu, Yunchao Ma, Yunhuan Yang, Jing Tan, Haoqiang Fan
  • • 来源： arXiv（cs.RO，2026-03-27）
  • • 核心价值： 具身智能下一阶段的分水岭，不只是模型会不会推理，而是推理结果能不能以工业可接受的时延和控制品质落到真机。

💻 开源生态

1. AgiBot 开源 genie_sim：把仿真、数据、评测三件事放进同一条具身工具链

摘要： genie_sim 是 AgiBot 近期开放的仿真平台仓库，GitHub 已达到约 727 Stars。结合官方介绍，它不只是一个仿真环境，而是把数字资产生成、场景泛化、数据采集、自动评测与物理仿真打包到同一流程里。The Robot Report 提到，相关平台覆盖超过 1 万小时开源合成数据、200 多项任务和 10 万多个评测场景，并开放了仿真资产、数据集与自动评测代码。它的重要性在于，行业越来越需要的不是单点 demo，而是可复用的数据生产与评测底座；因为只有当训练、数据和评测流程被标准化，模型结果才更容易复现、比较和快速迭代。

  • • 来源： GitHub / The Robot Report
  • • 核心价值： 开源社区正在把“数据生产线 + 仿真评测线”同时做出来，这对具身模型迭代效率的提升，往往比再开源一个单点策略模型更大。

🏢 机器人公司情报

1. Unitree 冲刺 IPO：人形收入占比、毛利率与销量结构披露出更真实的商业轮廓

摘要： Unitree 递交科创板 IPO 后，外界开始看到比“产品演示视频”更扎实的一组经营数据。The Robot Report 援引公开材料称，Unitree 2025 年营收约 2.48 亿美元；与此同时，其人形机器人均价从 2023 年约 8.5 万美元下降到 2025 年前九个月约 2.5 万美元，但公司整体毛利率却升至 59.8%。更关键的是，前九个月人形机器人已占核心营收的 51.5%，而四足机器人占 42.3%。这说明 Unitree 正逐步证明自己是有制造杠杆和成本控制能力的硬件公司。不过报道也提醒，当前人形收入仍主要来自科研教育和展示类场景，真正工业应用占比仍低。这意味着商业化已经前进，但离工业级规模落地还有距离。

  • • 来源： The Robot Report
  • • 核心价值： Unitree 最值得看的一点，不只是收入增长，而是“降价同时提升毛利”的制造效率信号，这比单纯讲故事更接近产业成熟标志。

结尾总结

今天的共性趋势很清楚：资本正在更集中地流向“可规模化的机器人系统能力”。

从 Apptronik、Machina Labs、RobCo 到 Konnex，钱开始投向量产、训练、数据回流、RaaS 协议和工厂基础设施；Realtime-VLA V2 则在补 VLA 真机部署短板，genie_sim 继续把数据与评测底座开放出来，Unitree 的 IPO 数据则提醒行业，真正的竞争迟早要回到成本、毛利、出货和客户结构上。因为具身智能走到今天，决定胜负的已经越来越不是单次惊艳演示，而是长期系统能力。
